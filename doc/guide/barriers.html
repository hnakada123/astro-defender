崩れるバリアの実装

小さなマスの配列で盾を表し、敵弾が触れた場所と周囲を削ります。

主な参照先：makeBarriers / barrierHit / erodeBarriers / drawBarriers

1枚の画像ではなく、マスの集まり

バリアは14列 × 10行、1マス4 pxの格子です。g[r][c] が1なら存在し、0なら穴です。生成時に上の角と下中央を切り抜き、描画時は値が残っているマスだけを塗ります。

画面座標をマスの番号に変える

まず敵弾とバリア全体の四角形を調べ、その内側で弾が重なる列・行だけを走査します。座標からバリアの原点を引き、マスの大きさで割って切り捨てると列番号になります。右端と下端の 0.01 は境界の次のマスまで含めないための調整です。

命中点の周囲を削る

実体のあるマスを見つけたら、blast の範囲を調べます。命中点と上下左右は確実に削り、周辺の一部は乱数で削るため、毎回少し違う穴になります。最初の命中を処理したら true を返し、敵弾の処理がその弾を消します。

barrierHit() を呼ぶのは敵弾の処理だけです。自機の弾は通常弾・3方向ショット・連結ビームのどれもバリアを素通りするので、自分の射撃でバリアが削れることはありません。バリアは敵弾から自機を守るための盾です。

敵弾のほかに、編隊がバリアへ下りてきた場合は erodeBarriers() が敵と重なったマスを削ります。合体レーザーとボムは barrierHit() を通らないため、バリアを壊しません。次のウェーブでは makeBarriers() で作り直します。

確かめてみよう

cell を変えると、バリアの見た目だけでなく全体の幅も変わります。マス数・マスの大きさ・全体の寸法の関係を確認してください。
