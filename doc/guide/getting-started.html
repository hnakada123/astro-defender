この解説の読み方

ゲームを動かし、画面の変化とコードを結び付けるところから始めます。

主な参照先：index.html / tests / doc

まずは遊んで、動きを観察する

ASTRO DEFENDER は、敵の編隊を撃ち落とす固定画面シューティングです。画面の動きは Canvas 2D、効果音と BGM は Web Audio で作られています。ゲーム本体はリポジトリ直下の index.html だけで動き、画像ファイルや音源ファイルを読み込む必要はありません。

この解説では、変数・関数・配列・オブジェクト・繰り返しの基本を知っている人を想定しています。初めてなら項目番号の順に、気になる仕組みがあるなら項目一覧から読み進めてください。

  • ゲームを開く。マウスで移動し、クリックを押し続けて射撃する。
  • 敵を減らしたときの速度、弾が当たったときの変化、ウェーブ終了時の画面を観察する。
  • 対応する解説を開き、関数名で本体のソースを検索する。

手元で動かす

リポジトリを取得したら、ルートの index.html をブラウザで開きます。HTTP 経由で確認する場合は、リポジトリのディレクトリで次のコマンドを実行し、表示されたポートの http://localhost:8000/ にアクセスします。

コード枠と確認課題の使い方

ファイル名・行番号の付いたコード枠は、今回の解説作成時の実ソースから抜粋しています。「ソースを見る」は GitHub の該当箇所へのリンクです。更新で行番号が変わった場合は、併記した関数名を検索してください。「説明用の例」は仕組みを小さく取り出した例です。

読み解くポイント

解説の対象は v1.0.1 のローカルソースです。各項目は個別の HTML ページなので、必要な章だけを開いたり、ブックマークしたりできます。コードや本文の閲覧に追加ライブラリは不要です。

確かめてみよう

1ウェーブ遊んでから、ゲームループ・入力・弾の処理の3項目を読んでみましょう。画面で見た動きが、どの変数の更新に対応するかを探します。
