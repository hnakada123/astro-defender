敵の編隊とウェーブ生成

50体の相対位置、折り返し、残り数とウェーブに応じた速度、射撃する敵の選び方と、ウェーブが進むと厳しくなる射撃を追います。

主な参照先：makeWave / form / formBounds / formSpeed / pickShooter / enemyFireInterval / maxEnemyBullets / aimedChance / enemyShot

行と列に共通の原点を足す

通常ウェーブの編隊は5行 × 10列です。敵は行 r と列 c を持ち、共通の原点 form.ox・form.oy を動かすと全体が移動します。敵1体ごとに速度を持たせる必要はありません。5の倍数のウェーブでは編隊の代わりにボスを生成します。

生きている敵の端で折り返す

formBounds() は生存中で編隊に残っている敵だけの左右端を調べます。画面の端から8 pxの境界を越えたら超過分を戻し、向きを反転して DROP だけ下へ進めます。空になった列を除いて幅を測るため、敵が減ると移動できる範囲が広がります。

残り数で難しさを変える

r は生存数の割合です。1 - r が大きいほど加速し、残り3体以下と最後の1体ではさらに加算します。最終的な速度は240で頭打ちです。アニメーションの切り替え周期も残り数に応じて短くなります。

ウェーブごとの基本速度 16 + (wave - 1) * 7 は、Math.min(wave - 1, 12) によってウェーブ13の毎秒100 pxで止まります。編隊は端で折り返すたびに DROP の14 pxずつ降りるので、横に速く動くほど折り返しが増えて速く降下します。基本速度が上がり続けると、50体そろった編隊が0.5秒ごとに折り返して一気に地上へ迫り、弾をかわす前に侵入で終わってしまいます。そのため後半は、次の節の射撃で難しくしています。

射撃と地上への侵入

pickShooter() は各列で最も下にいる敵を候補にし、そこからランダムに射撃役を選んで、その四角形を返します。突入中の敵はこの候補に入りません。

fireT が0になるたびに1発撃ち、次の発射までの時間を決め直します。間隔はウェーブで決まる基本値に乱数を掛け、さらに敵が減るほど短くします。画面内の敵弾が上限に達しているときは撃ちません。ウェーブ16からは別のタイマー volleyT で、ときどき1体が3方向に広がる弾をまとめて撃ちます。3発がすべて上限に収まるときだけ撃つので、上限を超えることはありません。

編隊内の敵が自機の高さまで到達したり自機と重なると、残機とは別に侵入によるゲームオーバーになります。

ウェーブが進むほど射撃が厳しくなる

射撃の厳しさは小さな関数に分けてあり、どれも wave だけから値を決めます。発射間隔はウェーブ13までは従来と同じ割合で縮み、その先も30ウェーブ前後まで少しずつ縮みます。画面内の敵弾の上限は、ウェーブ5の7発から4ウェーブごとに1発ずつ増え、最大12発です。

ウェーブ発射間隔の基本値敵弾の上限狙い撃ちの割合
11.15秒3発0%
60.80秒7発15%
130.31秒9発33%
200.25秒10発50%
300.18秒12発50%

ウェーブ6からは、編隊の弾の一部が自機を狙って斜めに飛びます。enemyShot() は狙い撃ちのとき、撃った瞬間の自機の位置へ届くように横の速さ vx を計算します。自機までの縦の距離を落下の速さで割れば到達までの時間が分かり、その時間で横の距離を進めばよい、という考え方です。横の速さは避けられるよう毎秒110 pxまでに制限します。狙い撃ちの弾は aimed を持ち、画面では赤く描いて、まっすぐ落ちる黄色の弾と見分けられるようにしています。

新しい攻撃が始まるウェーブ（6・11・16）とボスのレベルが上がるウェーブ（10・15・20）は WAVE_NEWS にまとめてあり、その直前のウェーブクリア画面で予告します（「14 ウェーブクリアと次のウェーブ」）。

確かめてみよう

formBounds() の a.flight を除外する条件を探してください。飛び出した敵が編隊全体の折り返し位置を変えないようにしています。続けて、enemyShot() で player.x = 200、x = 100、y = 200 のときの狙い撃ちの弾が、自機の高さで x=200 に届くことを計算で確かめてください。
