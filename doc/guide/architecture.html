1ファイルの全体構成

HTML・CSS・JavaScript の役割と、入力から描画までのデータの流れを整理します。

主な参照先：cvs / ctx / player / update / draw

画面の骨組みとゲーム本体

HTML はゲーム画面用の Canvas、必殺技と言語のボタン、操作説明を配置します。CSS は画面の大きさや周囲の装飾を担当します。自機・敵・弾は HTML 要素ではなく、JavaScript が Canvas に描く図形です。

層役割読む場所
HTMLCanvas・ボタン・操作説明を置く<body> の冒頭
CSS表示サイズ、枠、走査線を整える<style>
JavaScript状態を更新し、絵と音を出す<script>

入力・状態・描画を分けて読む

  1. 1. 入力keys や mouseX を更新
  2. 2. 計算update(dt) が状態を進める
  3. 3. 描画draw(t) が画面を作る

例えば右キーを押すと、入力イベントが keys.right を true にします。updatePlay() がそれを読んで player.x を増やし、drawGame() が新しい座標に自機を描きます。入力イベントと描画の間にゲーム状態がある、と考えると読みやすくなります。

ソースを探すための地図

まとまり主な名前
基本設定・文言W、H、STRINGS、T()
音と画像の準備beep()、musicTick()、makeSprite()、prerender()
ゲームの状態player、aliens、active、upgrades、special
ルールと入力makeWave()、activateLaser()、updateBoss()、イベント登録
フレーム処理update()、draw()、frame()
読み解くポイント

関数はファイル末尾からさかのぼって読む方法も有効です。ensureLoop() → frame() → update() と draw() の順に呼び出し先を追うと、プログラム全体の入口をつかめます。
