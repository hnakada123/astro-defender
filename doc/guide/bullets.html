弾の移動と衝突の順序

配列の逆順走査、弾が消える条件、シールドとミスの分岐を説明します。

主な参照先：pBullets / eBullets / damagePlayer / hitPlayer

弾は位置と速度を持つオブジェクト

自弾は毎秒470 pxで上へ進み、横方向の速度がある弾は xも変化します。画面外へ出たら削除対象です。敵弾は各オブジェクトの vy、必要なら vx を使って進めます。

衝突を調べる順番にも意味がある

順番自弾の処理
1画面外かどうかを調べる
2バリアと当たればバリアを削り、弾を消す
3敵弾と相殺する
4ボーナス円盤、ボスとの衝突を調べる
5通常の敵に当たれば撃破し、貫通数を減らす

dead が true になった弾は後続の対象を攻撃しません。連結ビームは敵への命中で pierce を減らし、残りがあれば別の敵も調べます。ただしバリアや敵弾への接触では通常弾と同様に消えます。合体レーザーは別の処理です。

削除しながら調べるなら後ろから

splice(i, 1) は要素を消し、後ろの要素を前へ詰めます。前から進むループだと、詰まってきた要素を飛ばすことがあります。末尾から先頭へ調べれば、まだ調べていない要素の位置は変わりません。

シールドと残機減少を分ける

ダメージを受けると、まずノーダメージ記録とコンボを解除します。シールドがあればそれを消費し、1.2秒の無敵時間を与えます。シールドがなければ hitPlayer() が残機を減らし、連結砲を解除して dying に移します。

確かめてみよう

damagePlayer() と hitPlayer() の役割を分けて確認してください。シールドで防いでもノーダメージボーナスの条件から外れる理由を説明できますか。
