自機の移動と入力

ポインターとキーボードを共通の状態にまとめ、移動速度と連射を制御します。

主な参照先：keys / mouseX / inputMode / releaseControls / updatePlay

イベントでは操作を覚えておく

ポインター移動は目標位置 mouseX、左右キーは keys.left と keys.right、射撃は shooting または keys.fire に記録します。実際の移動と弾の生成は、毎フレームの updatePlay() が担当します。

どちらの入力も速度を通して動かす

キーボードは左右の真偽値を -1・0・1の向きに変換します。ポインター操作は目標へ瞬間移動するのではなく、1回に進める距離を制限して追従します。エンジン強化の速度倍率は両方に効き、ポインターの追従上限はキーボード移動の2倍です。

clampPlayerX() は画面端で位置を制限します。連結砲があるときは砲の幅も考慮しますが、敵弾と当たるのは自機本体だけです。

長押しの射撃はクールダウンで調整する

player.cool が0以下で、通常弾数が上限未満なら発射します。基本間隔は0.27秒、連射強化中は0.12秒です。通常弾の上限は基本3、3方向ショットまたは連射強化中は12を条件判定に使います。連結ビームはこの通常弾数に数えません。

入力が残る場面をなくす

キーを離す、ポインターを離す、操作がキャンセルされる、といったイベントで入力を解除します。ポーズや強化選択への遷移時も releaseControls() を呼びます。ウィンドウがフォーカスを失うと、プレイ中なら自動でポーズになります。

確かめてみよう

左右キーを押したままポーズを入れてから、キーを離して再開します。移動が勝手に続かないことと、setPaused() の入力解除を対応させてください。
