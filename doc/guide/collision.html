四角形の当たり判定

4つの不等式で重なりを調べ、絵とは別に衝突範囲を定義します。

主な参照先：hit / playerRect / alienRectInto / SCRATCH

左右・上下の4条件をすべて満たす

x と y は四角形の左上、w と h は幅と高さです。Aの左がBの右より左、Aの右がBの左より右、さらに上下でも同じ条件を満たしたら重なっています。回転しない四角形による判定を AABB 判定と呼びます。

実験：四角形を重ねる

Aを左右に動かします。スライダーは矢印キーでも操作できます。

Aの右端がBの左端を超えると重なります。
読み解くポイント

比較は < と > なので、辺がぴったり触れるだけなら false です。見た目の光彩は当たり判定に含めません。

当たり判定の四角形を作る

自機の判定は幅26、高さ16の本体だけです。敵は編隊内なら行・列から、突入中なら flight の座標から判定範囲を作ります。この関数を共通にすることで、飛び方が変わっても弾の判定を共用できます。

計算途中のオブジェクトを再利用する

弾と敵の組み合わせを調べる処理では、SCRATCH に結果を書き込みます。大量の一時オブジェクトを作らないための工夫です。次の呼び出しで上書きされるため、保存せずその場で使います。独立した結果が必要な箇所では alienRect() を使います。

確かめてみよう

スライダーを126にすると、Aの右端は190になり、Bの左端に接します。127にしたときと判定を比べてください。
