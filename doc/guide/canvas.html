Canvas の座標と描画

内部座標と表示サイズの違い、文字描画、重ねる順序を確認します。

主な参照先：W / H / canvasX / dotScale / drawTextOn / draw

内部は480 × 640、見た目の大きさはCSS

Canvas の内部座標は左上が (0, 0)、右へ進むと x、下へ進むと y が増えます。CSS で画面を縮めても内部の480 × 640という寸法は変わりません。ゲーム中の速度や当たり判定は、この内部座標で計算します。

ポインターの座標を変換する

イベントの clientX から Canvas の表示位置を引き、表示幅に対する比率を求めて内部幅 W を掛けます。例えば表示幅が240 pxなら、左端から120 pxの位置は内部座標240になります。ポインターの移動とクリックのどちらでもこの関数で自機の目標位置 mouseX を求めます。ゲームで使うのは横方向だけなので、y方向の変換はありません。

文字も図形として描く

Canvas に描いた文字は DOM の文章とは別です。このゲームでは英数字と記号を、文字表から作ったドット文字（「05 文字列からドット絵を作る」）の長方形として描きます。文字の大きさ size から dotScale() でドット1個の大きさを整数倍で決め、1文字6ドットぶんずつ右へ進めます。中央揃えや右揃えのために先に文全体の幅を計算し、左端と基準線の座標を整数にそろえるので、点がにじみません。長方形はすべて1本のパスに加えてから fill() で一度に塗ります。タイトルロゴのように光彩 (shadowBlur) を付けるときも、光彩が文全体に1回だけかかります。

ドット文字にない文字、つまり日本語を含む文は、全体をシステムのフォント SYSTEM_FONT で fillText() により描きます。英字だけドット文字にすると、日本語より小さく見えて行の大きさがそろわないためです。SYSTEM_FONT は CSS と同じく、英字の字形が整った等幅フォントを OS ごとに選ぶ並びです。drawText() はこの関数へ本画面の ctx を渡す薄い窓口になっています。

後で描くものが手前になる

draw() は背景、ゲーム内の物体、HUD、画面中央の案内の順に重ねます。いちばん下の星雲の画像は不透明で画面全体を覆うので、前のフレームの絵はこれで塗り隠されます。画面を揺らすときだけは画像がずれて端に隙間ができるため、先に下地の色で全面を塗ります。ctx.save() と ctx.restore() は座標変換などの描画設定を保存・復元するためのもので、ゲームの状態や画像そのものを保存する命令ではありません。

確かめてみよう

ゲーム画面のCSS幅を変えても、自機がポインターを追う位置が合うか確認してください。canvasX() が「見えている幅」と「内部の幅」をつないでいます。
