ゲームロジックのテスト

ブラウザ部分を置き換え、本番のJavaScriptに対してルールを検証します。

主な参照先：tests/helpers/game.cjs / node:test / vm

本体からスクリプトを取り出して実行する

テスト用にゲームを別実装するのではなく、game.html の script 内を読み込んで Node.js の vm で実行します。Canvas、DOM、音声、時刻、フレームの予約などは簡単な代用品へ置き換えます。ゲームのルールを担う関数は本番のものです。読み込んだ後は startGame() を呼び、敵の射撃・ボーナス円盤・突入のタイマーを Infinity にして、偶然の出来事がテストに割り込まないようにします。Bカプセルを指定した回数だけ拾わせる collectBeam(times = 1) もここで定義しており、collectBeam(4) で連結砲を4門そろえられます。

状態を用意し、操作して、結果を調べる

このテストは近い敵・遠い敵・敵弾・バリアを用意し、ボムを使った結果を調べています。近い敵だけが消え、敵弾が空になり、バリアが保持され、無敵時間が付くことを検証します。直後の再使用が拒否されることまで含めて仕様を表しています。

実行する

2つのファイルに合計40個のテストがあります。

ファイル主な対象
tests/beam-link.test.cjs連結砲の取得（1個で1門）・射撃（1門につき画面内1発）・併用・バリアの素通り・持ち越し・画面端・ミスで2門減（9個）
tests/arcade-features.test.cjsレーザー（照射中の減速を含む）・ボム・ボス（レベルごとの攻撃）・コンボの段・ウェーブクリア後の自動進行・後半の射撃（狙い撃ち・突入敵の射撃・3方向弾・予告）・突入・入力・1UP・弾のすり抜け防止・連続ウェーブ（31個）

このテストでは分からないこと

Canvasの描画命令と音声出力を置き換えているため、実際の絵の崩れ、文字の見切れ、音の聴こえ方、描画速度は確認できません。ロジックのテストに加え、ブラウザで通常プレイ・ウェーブの切り替わり・ボス戦・ポーズを確認します。

確かめてみよう

連結砲やボムの上限、無敵時間を変更するときは、正常に使える場合に加え、上限到達時・資源不足・ポーズ中の結果も確認してください。
