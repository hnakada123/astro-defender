ウェーブクリアと強化3択

戦闘を止めて候補を選ばせ、強化を保ったまま次のウェーブを作ります。

主な参照先：openUpgrades / chooseUpgrade / UPGRADE_DEFS / makeWave

通常の敵もボスもいなくなったらクリア

aliveN === 0 && !boss がクリア条件です。編隊から突入した敵も生存数に含むので、画面外へ飛び去っただけではクリアになりません。敵弾や自弾を消し、入力を解除して clear に移ります。ノーダメージなら 500 + wave * 100 点を加えます。

上限に達した強化を除いて抽選する

ビーム・速度・回収には最大レベル5が設定されています。上限の候補を除いてから、配列から1つずつ取り出すため重複しません。レベルを持たない緊急整備・防衛補給・エネルギー補給が残るので、3つの恒久強化がすべて上限でも3択を作れます。

選択を確定してからウェーブを進める

関数の冒頭で状態と選択の有効性を検査します。1回選ぶとすぐに play へ移るため、同じ入力が重なっても二重に次へ進みません。makeWave() は敵や弾やバリアを作り直しますが、恒久強化のレベルを初期化しません。

候補効果
ビーム強化通常の連結ビームの貫通数・対ボス威力、合体レーザーの幅・威力を増加
エンジン強化基準の移動速度へ1レベルあたり15%を加算
回収フィールドカプセルを引き寄せる範囲を拡大
緊急整備残機+1。最大5なら1000点
防衛補給ボム+1（最大3）、シールド、300点
エネルギー補給ゲージ満タン、300点
確かめてみよう

startGame() と makeWave() の初期化項目を比較してください。新しいゲームで消える強化と、次のウェーブへ持ち越す強化が区別できます。
