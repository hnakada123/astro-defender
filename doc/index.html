ASTRO DEFENDERゲームの動きを、
コードから読み解く。

1つの HTML ファイルで動くシューティングゲーム。
画面に描く、敵を動かす、弾を当てる、音を鳴らす。
その仕組みを、実際のソースと一緒に学ぶ解説です。
