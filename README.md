# ASTRO DEFENDER — NEON ARCADE EDITION

*[English version / 英語版はこちら](README.en.md)*

**▶ 今すぐプレイ: <https://hnakada123.github.io/astro-defender/>**

ブラウザだけで遊べる、マウス操作のネオレトロ風固定画面シューティングゲームです。
外部ライブラリ・外部素材は一切使わず、`index.html` 1 ファイルで完結しています。

クラシックな編隊シューティングをベースに、ネオングロー演出・コンボ倍率・
パワーアップ・シンセウェイブ風BGMを備えたモダンアーケード仕様です。

表示は日本語と英語に対応しています。初回はブラウザの言語設定から自動で選ばれ、
画面下のボタンでいつでも切り替えられます（選択内容は localStorage に保存されます）。

## 使用技術

- **HTML / CSS / JavaScript**（Vanilla JS。フレームワーク・外部ライブラリ・ビルドツール不使用）
- 描画: **Canvas 2D API**（ドット絵スプライトは実行時にコードから生成）
- サウンド: **Web Audio API**（効果音・BGM をリアルタイム合成、音源ファイルなし）
- ハイスコア保存: **localStorage**

## 起動方法

`index.html` をブラウザ（Chrome / Firefox / Edge など）で開くだけで遊べます。

ローカルサーバー経由で開きたい場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## ルール

- 敵の編隊を全滅させると強化を1つ選んで次のウェーブへ進みます
- 5ウェーブごとに大型戦艦が登場。左右の砲台を壊し、中央のコアを撃破するとクリア
- 敵弾や突入する敵に当たるとミス。残機 0、または敵の編隊が地上まで侵攻するとゲームオーバー
- 画面上部をときどき横切るボーナス円盤を撃つと 50〜300 点
- 緑のバリアは弾を防ぎますが、撃たれるたびに崩れていきます
- 5000 点ごとに残機が 1 つ増えます（最大 5）
- ハイスコアはブラウザの localStorage に保存されます

## モダンアーケード要素

- **コンボ倍率** — 約 2 秒以内に撃破をつなぐと倍率が上がり、最大 ×8。
  被弾または時間切れでリセット
- **パワーアップ** — 敵がまれに落とすカプセルを拾うと発動
  - `W` 3方向ショット（8秒） / `R` 連射強化（8秒） / `S` シールド（被弾1回無効）
  - `B` ビーム砲連結 — 取得するたびに自機の左右に1門ずつ追加（最大4門）。
    通常ショットと同時にビームを発射し、`W`・`R`・`S` と併用できます。
    時間制限はなく次のウェーブにも持ち越せますが、ミスすると解除されます
    （シールドで防いだ場合は維持）。画面下部に連結数を表示します
- **パーフェクトボーナス** — ノーダメージでウェーブクリアするとボーナス得点
- **演出** — ネオングロー、弾のトレイル、パーティクル爆発、衝撃波リング、
  ヒットストップ、画面シェイク、パララックス星空と星雲
- **BGM** — Web Audio でリアルタイム生成するシンセウェイブ風ループ

## 新しい戦闘・強化システム

- **合体レーザー** — 敵の撃破やボスへの通常攻撃でゲージを充電し、満タンで1.2秒間の
  貫通レーザーを発射。射線上の敵・敵弾を一掃し、バリアは傷つけません。
  連結ビーム砲が多いほど太く強力になり、連結砲がなくても使用できます。
  発射しても連結砲は失われません。レーザーによる撃破では再充電しません
- **大型戦艦とのボス戦** — 左右の砲台が中央コアを保護しています。
  砲台からの拡散弾に加え、赤い範囲で1.1秒前に着弾位置を予告するレーザーを使用。
  予告位置は固定されるので、赤い範囲から離れて回避できます。撃破でボムを1個補給
- **強化3択** — 毎ウェーブ、以下の候補からランダムに3つ提示。選択するまで戦闘は停止します。
  ビーム・速度・回収の強化はそれぞれ最大Lv.5で、ミスしても維持され、新しいゲームでリセットされます
  - ビーム強化: 連結ビームの貫通数・対ボス威力、合体レーザーの幅・威力を強化
  - エンジン強化: 移動速度 +15%（マウス・キーボード両対応）
  - 回収フィールド: 近くのカプセルを自動で引き寄せる範囲を拡大
  - 緊急整備: 残機 +1（最大5、満タンなら1000点）
  - 防衛補給: ボム +1（最大3）、シールド、300点
  - エネルギー補給: レーザーゲージ満タン、300点
- **突入する敵** — ウェーブ2から、予告後に急降下・ジグザグ・横からの突入を行う敵が出現。
  撃ち逃した敵は編隊に戻り、撃破するまでウェーブは続きます
- **緊急回避ボム** — 初期2個、最大3個。画面全体の敵弾を消し、自機から240px以内の敵を撃破。
  ボスの各部位にもダメージを与え、ボスの予告・発射中のレーザーを中断します。
  使用後1.6秒間は無敵。バリアは傷つけず、ミスでは補充されません

## 開発用テスト

Node.js の組み込みテスト機能で、連結砲・必殺技・ボス・強化選択・突入する敵・入力・
ミスやウェーブ遷移時の動作を確認できます（追加パッケージ不要）。

```sh
node --test tests/*.test.cjs
```
